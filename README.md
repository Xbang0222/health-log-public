# health-log

用日常话记饮食和体重，让 AI 帮你理解、估算、补充和更正，记录保存在你自己的账本目录。
health-log 是本地记账引擎，配合能读文件、执行命令的 AI 使用；目前没有独立网页或手机应用。

> 你：早上两个鸡蛋，一盒全脂奶。
> AI：已记早餐：鸡蛋 2 个、全脂奶 1 盒，份量按常见大小估算。
> 你：鸡蛋其实只吃了一个，牛奶没变。
> AI：鸡蛋已改为 1 个，牛奶不变。

## 第一次使用

把项目交给你正在使用的工具型 AI，可以直接说：

> 请帮我用 health-log 记饮食和体重。先检查环境、准备账本，告诉我账本存在哪里，
> 再简单教我怎么记。我会用日常话告诉你吃了什么；说不清时只问必要信息，明确的部分先完成。
> 我暂时只想记录，不需要先设目标或填写个人资料。

AI 会按[安装说明](docs/portable-install.md)检查 Python、准备项目环境和食物库，
使用你选定的持久目录保存账本。如果已有账本，告诉它位置，接着用即可。
你不需要学习命令，也不必先提供年龄、身高、体重或热量目标；这些都不是记一餐的前提。
如果当前 AI 只能聊天，不能读写文件或执行命令，它需要先说明这个限制，不能只在回复里声称已经保存。

准备好后，从一句“早餐吃了两个鸡蛋”开始。
完整例子和使用边界见[普通人使用指南](docs/user-guide.md)。

## 平时怎么说

| 想做什么 | 直接这样说 |
| --- | --- |
| 记饮食 | “午饭吃了一碗面。” |
| 补记 | “昨天晚饭还有半碗米饭，刚才忘了说。” |
| 补充或更正 | “刚才还喝了一盒奶。”“那碗面只吃了半碗，其他没变。” |
| 记体重 | “今天早上体重 72.4 公斤。” |
| 查记录 | “今天记了什么？”“看看最近两周的记录。” |
| 停止一件事 | “这个先不记了。”“刚才那个删除取消。” |

AI 应主动处理口语、日期、餐次和指代，不让你反复填写表格。
“一碗面”已有数量，可以按常见份量估算并说明是约数；只说“吃了面”则需要补一个大致数量，
不会擅自写成一碗。疑似语音错字或记录冲突，只追问影响结果的歧义，能确定的部分先完成。

在当前会话里，AI 可以查账本后提醒尚未完成的记录，或你明确想记录却还没记好的内容。
**账本没记录不等于没吃，没设目标也不是资料不全。** 提醒要简短、适时；你说取消或不想补，就停止追问。
这不是后台提醒服务，关闭会话后不会自动监测或发送通知。

## 换 AI 或换电脑

记录在账本里，不依赖某次聊天的记忆。告诉新 AI 两个位置：

- **程序项目**：[health-log-public](https://github.com/Xbang0222/health-log-public) 提供可复用源码、模板和使用文档；不放个人记录、私人设置或账本密钥。
- **个人账本项目**：私有保存你的饮食、体重、个人设置、规则、历史和完整 `.hl`，放在持久目录。

程序按 MIT 许可公开，个人账本始终独立保存在你的私人目录或私有仓库。
开发测试与过程材料保留在私有开发仓库，与个人账本分开；公开源码从审阅后的允许清单单独生成，不带旧仓库历史。

让它优先读取账本中的 `HEALTH_LOG_V2.md`；没有这个文件时，再读账本 `AGENTS.md`。
检查账本后继续使用，不要在程序目录另建一份记录。AI 接入细节见[接入指南](docs/agent-integration.md)。
程序更新不会自动覆盖已有账本指南；需要更新用法时，让 AI 保留你的个人偏好后合并新版规则。

换电脑时复制**整个账本目录，包括隐藏的 `.hl`**，并另留备份；只复制 `log/` 或 Git 历史不完整。
程序可以重新下载，程序目录里的 `.venv` 在新电脑重新建立。
具体步骤见[安装与换电脑](docs/portable-install.md)，旧格式账本见[迁移说明](docs/migration.md)。

## 运行与数据边界

首次安装需要 Python 3.11 或以上，下载依赖和食物库通常需要网络；不要求 Git、uv、全局 `hl` 或宿主 hooks。
本地引擎在依赖、食物缓存备齐后可离线读写，但**通过云端 AI 对话仍需要该 AI 服务的网络连接**。
完全离线使用还取决于你选择的 AI 是否能在本地运行并调用工具。
用云端 AI 时，对话和工具返回的必要记录会由它的服务处理；本地保存账本不代表所有信息都不离开电脑。

AI 负责理解原话，引擎负责计算、估算标记、保存、更正版本和操作历史。AI 可能理解错，你可以直接纠正。
默认反馈只说记了什么及必要的估算提示；需要营养明细时再问。未知营养不会算成零，也不会把估算说成实测。
体重是目前支持的身体记录；营养目标由你自行决定，系统不做医疗诊断或拍照识别。

食物数据来自[中国食物成分表数据](https://github.com/Sanotsu/china-food-composition-data)和
[薄荷食物库数据](https://github.com/jarheadjoe/scrapy_boohee)，下载到你的账本并校验固定版本。
仓库不附带这些第三方营养数据。薄荷数据和模型估算均保留估算标记。
