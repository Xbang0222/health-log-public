# 私有实际项目与公开分发

已有私有 `health-log` 仓库就是日常使用和开发的唯一实际项目，程序、食品数据、个人账本和私有开发材料都可在这里保存。
不需要再创建一个使用副本。新用户才从公共模板创建一次自己的私有项目，或下载到私人持久目录。

`health-log-public` 只保存按允许清单导出的公开程序，不承担个人记账，也不接收私有仓库的完整历史。
日常记录与开发由同一根 `AGENTS.md` 按任务分派；测试只使用临时合成账本，不用正式数据。

| 内容 | 私有项目中的位置 | 公开分发 |
| --- | --- | --- |
| 程序、通用根规则、安装入口和文档 | `src/hl`、`scripts`、根文档与 `docs` | 按程序允许清单导出 |
| 自有食物概念、菜谱、量词与模式 | `src/hl/data` | 随运行资源导出 |
| 食品库来源和校验清单 | `data/foods/README.md`、`manifest.json` | 可公开，不含完整第三方数据 |
| 完整第三方食品原始数据与整理快照 | `data/foods/raw`、`compiled` | 私有保留，不按项目 MIT 许可再分发 |
| 个人记录、配置、计划、默认与食品标签 | `hl.toml`、`log/`、计划、默认、`foods/` | 排除 |
| 个人偏好和旧自定义规则 | `PERSONAL_RULES.md`、实际个人指南 | 排除；根 `AGENTS.md` 保持通用 |
| 私有测试、夹具、对话与审查材料 | 私有仓库或已保留的私有归档 | 排除；不要求另建产品项目 |
| 密钥、收据、事务、完整操作历史与缓存 | `.hl` | 排除，也不进入 Git；完整备份必须包含 |
| API 凭据、宿主私有设置与本机环境 | 私有配置、`.venv` 等 | 排除，不进入 Git |

公开模板不包含维护者的个人记录、测试、受限数据或旧历史；用户创建自己的项目后，可以在同一仓库继续使用和开发。
个人数据始终保持私有，不直接将整个私有项目推到公共仓库，也不将私有仓库改为公开。

## 保存自己的项目

私有项目的 Git 跟踪程序、账本、设置、食品数据、个人偏好及私有测试；已有配置好的私有仓库直接沿用。
`.hl`、凭据、宿主私有配置和 `.venv` 仍排除。**同一个项目，不等于所有秘密都要进 Git。**

公开导出的 `.gitignore` 会继续忽略个人数据，防止记录误入公共仓库。新用户从公共模板建立私有副本后，
确认远端是自己的私有仓库，再在该副本中解除账本、设置、食品数据、个人规则和私有测试的忽略，
保留密钥、`.hl`、凭据与运行环境的排除规则；核对实际跟踪文件后再提交。这个调整只需做一次，
不必为了跟踪自己的账本另建仓库，也不要把私有忽略规则直接用于公共分发。

`git push` 只同步已提交内容，不保存未提交或未跟踪文件，更不包含完整 `.hl`。
备份、换机仍要复制整个项目和隐藏 `.hl`；`.venv` 可不搬，在新电脑重新 bootstrap。
具体核对与恢复见[迁移说明](migration.md)。

## 导出公开版本

在私有项目运行：

```sh
python3 scripts/export_public.py /新的导出目录
```

目标必须是新目录或空目录。导出器以 `pyproject.toml` 为唯一程序允许清单，
并使用其 force-include 映射放入专用的公开 `.gitignore`，不会复制私有仓库的跟踪范围或 `.git` 历史。
个人账本、`PERSONAL_RULES.md`、实际个人指南、测试、过程材料、凭据和第三方完整快照不在公开清单中。
根 `AGENTS.md` 等公共规则必须保持通用，个人偏好不能写进允许公开的文件。

先核对导出内容，再将它用于公开仓库和发布。公开仓库建立独立的分发历史，导出本身不推送，
也不改变私有仓库可见性。`.gitignore` 不是发布清单，不能清除旧历史中的私有数据。
wheel、源码包也按对应清单构建并检查实际成员，不复用未经核对的旧包。

## 更新自己的项目

只更新允许的程序文件，保留账本、设置、食品数据、`.hl`、`PERSONAL_RULES.md` 和旧个人指南。
公开新版未包含的私有内容不能因此被删除；新操作规则需比较后合并，格式迁移仍是单独步骤。
开发、备份与公开导出都围绕同一个私有项目完成。

公开源码入口是 [health-log-public](https://github.com/Xbang0222/health-log-public)。程序与自有规则采用
[MIT 许可证](../LICENSE)，第三方食品数据范围见[数据说明](../data/foods/README.md)。
不公开私有测试和过程材料是本项目的分发选择。
